# Redmine Polls

Плагин опросов для Redmine: создание опросов в проектах, голосование с учётом одного голоса на пользователя, несколько вариантов, свой вариант, отмена голоса и выгрузка отчёта администратором.

Распространяется свободно по лицензии **MIT** (см. `LICENSE`).

## Возможности

- Опросы внутри проектов Redmine (модуль «Опросы»).
- Несколько опросов в одном проекте, открытые и закрытые.
- **Один голос на пользователя** — повторное голосование заменяет выбор, повторный голос исключён.
- **Мультивыбор** — администратор может разрешить выбор нескольких вариантов (чекбоксы).
- **Свой вариант** — по разрешению администратора участник может добавить собственный вариант.
- **Отмена голоса** — участник может снять свой голос.
- **Результаты** — количество и процент голосов по каждому варианту + список проголосовавших.
- **Отчёт CSV** — администратор выгружает отчёт (Вариант; Пользователь; Логин; Email; Дата).

## Требования

- Redmine **7.0** и выше (Rails 8).
- Языки интерфейса: русский и английский.

## Установка

1. Скопируйте папку `redmine_polls` в каталог плагинов Redmine:
   ```
   cp -r redmine_polls /opt/redmine/plugins/
   ```
2. Выполните миграцию:
   ```
   cd /opt/redmine && RAILS_ENV=production bin/rails redmine:plugins:migrate
   ```
3. Перезапустите Redmine (Passenger):
   ```
   touch /opt/redmine/tmp/restart.txt
   ```

## Настройка

В проекте: **Настройки → Модули** → включите **«Опросы»**.

Права (Администрирование → Роли и права):

| Право | Что даёт |
|---|---|
| Просмотр опросов | видеть список опросов и результаты |
| Участие в опросах | голосовать и отменять голос |
| Управление опросами | создавать/редактировать/закрывать/удалять, выгружать отчёт |

## Использование

- **Создание опроса**: раздел «Опросы» → «Новый опрос» → название, описание, варианты (кнопка «+ Добавить вариант»), опции:
  - «Открыт» — снять галочку, чтобы закрыть опрос;
  - «Разрешить выбор нескольких вариантов»;
  - «Разрешить добавлять свой вариант».
- **Голосование**: выбрать вариант (или несколько) → «Проголосовать». Повторная отправка заменяет выбор.
- **Отмена**: после голосования — кнопка «Отменить голос».
- **Свой вариант**: если разрешено, вписать текст в поле «Свой вариант» и проголосовать — он станет отдельным вариантом.
- **Отчёт**: на странице опроса «Скачать отчёт (CSV)» (только для тех, у кого право управления).
